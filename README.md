# Vrinda Store Data Analysis Dashboard

## Project Overview
This project is an interactive Excel dashboard created using Vrinda Store sales data.

The dashboard provides insights into:
- Sales vs Orders
- Men vs Women purchasing behavior
- Order Status
- Top Performing States
- Age vs Gender analysis
- Sales Channels

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning

## Dashboard Preview

![Dashboard](dashboard.png)

## Key Insights
- Women contribute higher sales than men.
- Amazon is the highest contributing sales channel.
- Maharashtra and Karnataka are top-performing states.
- Most orders are successfully delivered.
